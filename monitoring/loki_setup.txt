Grafana Loki local setup and verification


Prerequisite: Docker Desktop is running.

1. Install Docker's Loki logging driver once (the `loki` driver is not built into Docker):

   docker plugin install grafana/loki-docker-driver:3.3.2 --alias loki --grant-all-permissions

2. Start Loki from the repository root:

   docker run -d --name loki -p 3100:3100 -v "${PWD}/monitoring/loki-config.yml:/etc/loki/local-config.yaml" grafana/loki:3.0.0 -config.file=/etc/loki/local-config.yaml

3. Confirm Loki is ready:

   curl --fail http://localhost:3100/ready

4. Build and run the application, forwarding Docker logs to Loki:

   docker build -t devops-intern-final:latest .

   docker run --rm --name hello-devops --log-driver=loki --log-opt loki-url="http://localhost:3100/loki/api/v1/push" --log-opt loki-external-labels="job=hello-devops" devops-intern-final:latest

   The Loki driver runs in the Docker daemon, so `localhost:3100` reaches the
   host-published Loki port on Linux, macOS, and Docker Desktop. It does not
   rely on `host.docker.internal`.

5. Query the forwarded log with the Loki HTTP API:

   curl --get --data-urlencode 'query={job="hello-devops"}' http://localhost:3100/loki/api/v1/query_range

   The JSON response must contain `Hello, DevOps!`. Copy the command output
   into `docs/verification.md` after running it.

6. Stop and remove Loki after testing:

   docker rm -f loki

Expected log message: Hello, DevOps!
